## Kaira Mascot

The current Kaira koi mascot was generated using ChatGPT / OpenAI image generation based on prompts, creative direction, selection, and integration decisions made by the project author.

The koi was selected to replace an earlier squirrel mascot concept.

This change was made as a branding decision after identifying another existing application that already used a squirrel as a recognizable mascot. Kaira therefore moved toward a koi identity to create a more distinct visual direction.

Where AI-generated visual assets are used, this repository identifies that contribution for transparency.
